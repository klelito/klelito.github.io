## Context

Information about orders, requests for quotation and technical documentation was scattered across spreadsheets, e-mail and network folders.

## Problem

The team lost time hunting for the current version of documents and chasing order status.

## Solution

A single web application with modules for orders, RFQs, documentation and service, with per-department permissions.

## Outcome

More than 40 people use the platform every day; order status is visible in one place.

## My role

- designed the architecture and data model,
- implemented the backend and frontend,
- containerized and deployed it.
