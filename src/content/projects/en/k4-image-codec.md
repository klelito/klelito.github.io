## Context

A computer graphics course project at Cracow University of Technology.

## Solution

A C++ program using SDL derives a reduced colour palette with the Median Cut algorithm (including a grayscale variant), maps pixels to the nearest palette colour and saves the image in a custom K4 format in 4- and 8-bit variants, with a written format specification.

## My role

- Median Cut quantization and pixel operations,
- writing and reading the K4 format.
