## Context

Production team leaders and managers use SAP Business One and Rewident data to plan resources and review processes. The report generator makes this data available in a Windows application, with Excel export for further analysis.

## Solution

Building on an existing template, I develop the application and create new SQL reports around users' needs. Reports are loaded from files: users select a data source and report, enter any available parameters and view the results in a table. A standard new report can be added as a SQL file without rebuilding the application forms.

The application contains 14 SAP scripts and 2 Rewident scripts. They cover production planning, components and product structures, inspection results and SMD product comparisons. Results can be exported to Excel.

## Outcome

The reports help team leaders and managers allocate resources, improve production processes and review component use. Additional reports allow the tool to address new questions arising in everyday work.
